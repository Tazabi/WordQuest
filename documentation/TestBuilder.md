# Добавление тестов при помощи TestBuilder

## Подготовка

Импорты и подготовка нужных атрибутов
```
from app import db, app
# Важные атрибуты
from auxiliaries.data_manager import DataManager, TestBuilder
# Собственно объекты DataManager и TestBuilder

DM = DataManager(Test, Word, Question)
# Данный объект инициализируется после
```

Объект TestBuilder работает с базой данных через интерфейс SQLAlchemy. Дополнительные манипуляции производить не нужно: всё работает из коробки, нужно лишь пользоваться нужными методами и подавать аргументы в нужном формате.

## Работа

Для начала работы нужно открыть контекстный менеджер.

```
with app.app_context()
    # без импортированного app мы не получим доступ к базе данных

    # вы можете дропнуть все стандартные таблицы и схемы, или не делать этого
    # db.drop_all()
    # db.create_all()
```

Добавление тестов реализуется при помощи паттерна разработки Builder (Конструктор). Инициализация объекта добавленного теста происходит при помощи открытия объекта в программном интерфейсе Builder:

```
(
    TestBuilder(DM, db.session)
)
```

Для добавления конкретики тесту нужны включенные в него слова, а также вопросы. Мы сигнализируем о добавлении новых слов или вопросов при помощи методов.

### Методы

#### .create_test(title: str, level: str, section: str, order: int)

Метод `create_test` принимает 4 аргумента:
- Название теста (`str`, напр. "Глагол TO BE")
- Уровень сложности теста (`str`, напр. "Elementary")
- Раздел, в котором находится тест (`str`, напр. "Verbs")
- Порядок расположения теста (`int` от 1 до +бесконечности)

Пример использования
```
(
    TestBuilder(DM, db.session)
    .create_test("TO BE: Глагол-связка",
                 "Elementary",
                 "Verbs",
                 1)
)
```

#### .batch_words(category: dict[str, dict], list[str])

К тесту можно привязать слова. Для этого надо воспользоваться методом `batch_words`. Он добавляет несколько слов из словаря `category` по ключам из списка `words`.

**category**
Словарь (`dict[str, dict]`), структурированный следующим образом:

```
{
    "key": {
        "word_en": "key",
        "word_ru": "ключ",
        "pos": "noun"
    }
}
```
где `word_en` - это английский вариант слова, `word_ru` - его русское соответствие, а `pos` - это часть речи (напр. "noun").

Вы можете воспользоваться уже готовым словарем из файла `dictionary.py`, например:

```
from auxiliaries.library.dictionary import VERB_DICTIONARY as VDICT
```

О том, как создавать и поддерживать такие словари смотрите в документации `DictionaryBuilder`.

**words**
Это непосредственно список ключей, по которым из *category* будут извлекаться слова. Например:

```
["key", "word", "phrase"]
```

*Важно!*: *words* отсылает к ключам в самом словаре *category*, а не к английским или русским вариантам слов непосредственно. Слова из списка *words* не будут добавлены, в базу данных будет включена информация под соответствующими ключами из словаря *category*.

**Пример**
```
    (
        TestBuilder(DM, db.session)
        .create_test("TO BE: Глагол-связка",
                     "Elementary",
                     "Verbs",
                     1)
        .batch_words(VDICT, ['am', 'are', 'is', 'continue'])
    )
```

#### .word(**kwargs)
Если по какой-то причине вам нужно добавить слово отдельно, используйте метод `word`. Он добавит слово, принимая в качестве ключевых аргументов ключи и значения из словаря, в котором есть ключи "word_en", "word_ru" и "pos". Значения под этими ключами должны быть строковыми. Именно эти значения будут использованы при добавлении в базу данных.

```
    (
        TestBuilder(DM, db.session)
        .create_test("TO BE: Глагол-связка",
                     "Elementary",
                     "Verbs",
                     1)
        .word(**NDICT['students'])
    )
```

#### .qbatch_info(category: list[tuple])
Если вам нужно добавить "информативные" вопросы с текстом вопроса и одним ответом, используйте данный метод. Аргументом для данного метода является список кортежей, где на первом месте стоит текст вопроса, а на втором - текст ответа.

Вы можете воспользоваться готовыми кортежами из файла `challenge_info`, например:

```
from auxiliaries.library.challenge_info import TOBE1, THIS1
```

Пример использования метода:
```
    (
        TestBuilder(DM, db.session)
        .create_test("TO BE: Глагол-связка",
                     "Elementary",
                     "Verbs",
                     1)
        .qbatch_info(TOBE1)
    )
```

Альтернативно, вы можете попробовать использовать свои кортежи на месте, добавляя их динамически при помощи вариации метода - `.qbatch_arginfo`:

```
    (
        TestBuilder(DM, db.session)
        .create_test("TO BE: Глагол-связка",
                     "Elementary",
                     "Verbs",
                     1)
        .qbatch_arginfo(
            ("Who are we?", "teachers!"),
            ("What do we want?", "an easy way to teach English!"),
            ("When do we want it?", "now!")
        )
    )
```

#### .qbatch_choice(category: dict[str, dict], qlist: list[str])
Для добавления в базу данных доступны вопросы с выбором ответа. Информация о них (category) должна быть организована так:

```
{
    "key": {
        
    }
}
```
